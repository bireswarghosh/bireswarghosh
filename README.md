## 🐍 Contribution Snake (ঐচ্ছিক কিন্তু eye-catching)

> Snake animation চাইলে: repo `bireswarghosh/bireswarghosh`-এ `Settings → Actions → General → Workflow permissions → Read and write` দাও, তারপর `.github/workflows/snake.yml` ফাইলে নিচের workflow বসাও।

```yaml
# .github/workflows/snake.yml
name: Snake
on:
  schedule: [{ cron: "0 0 * * *" }]
  workflow_dispatch:
jobs:
  snake:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: bireswarghosh
          outputs: dist/github-snake.svg
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
